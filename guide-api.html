Guide : Clés API & Regex TikTok oEmbed

Mistral AI · Agnes AI · Extraction d'image depuis un oEmbed TikTok

🔑 Obtenir une clé API Mistral AI

Mistral Étapes

  1. Créez un compte ou connectez-vous sur console.mistral.ai.
  2. Dans la barre latérale gauche, cliquez sur API Keys.
  3. Cliquez sur Create new key.
  4. Donnez un nom à la clé (ex. mon-projet) et, si vous le souhaitez, définissez une date d'expiration.
  5. Cliquez à nouveau sur Create new key.
  6. Copiez immédiatement la clé et stockez-la dans un endroit sûr (gestionnaire de mots de passe, coffre-fort de secrets).
⚠️ La clé complète n'apparaît qu'une seule fois. Vous ne pourrez plus la retrouver après avoir fermé la fenêtre de confirmation.

Le mode gratuit est activé par défaut, sans carte bancaire, avec des limites d'utilisation.

Test rapide avec curl :

curl https://api.mistral.ai/v1/chat/completions \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mistral-small-latest",
    "messages": [{"role": "user", "content": "Bonjour !"}]
  }'

Documentation officielle : docs.mistral.ai.

🔑 Obtenir une clé API Agnes AI

Agnes Étapes

  1. Rendez-vous sur la plateforme internationale Agnes AI et inscrivez-vous ou connectez-vous.
  2. Ouvrez la section API Key dans la console développeur.
  3. Créez une clé, puis copiez-la et stockez-la immédiatement. La clé complète n'est normalement affichée qu'une seule fois.
  4. Envoyez la clé dans l'en-tête d'autorisation pour chaque requête API : 
    Authorization: Bearer YOUR_API_KEY
🔐 N'exposez jamais une clé API dans du code côté client, des dépôts publics, des captures d'écran ou des journaux. En cas de perte ou d'exposition, supprimez-la immédiatement et créez-en une nouvelle.

URL de base & endpoints

URL de base pour le service international :

https://apihub.agnes-ai.com/v1

Endpoints principaux :

  • /chat/completions — texte
  • /images/generations — images
  • /videos — vidéo

Exemple de requête :

curl https://apihub.agnes-ai.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "agnes-2.5-flash",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

Documentation : wiki.agnes-ai.com · FAQ.

🖼️ Extraire l'image d'un oEmbed TikTok (regex)

1. Fonctionnement de l'API oEmbed TikTok

L'API oEmbed de TikTok renvoie un objet JSON contenant notamment le champ thumbnail_url, qui est l'URL de l'image miniature de la vidéo.

Endpoint :

GET https://www.tiktok.com/oembed?url={URL_DE_LA_VIDEO}

Exemple de réponse (extrait) :

{
  "version": "1.0",
  "type": "video",
  "title": "Scramble up ur name & I'll try to guess it❤️",
  "author_url": "https://www.tiktok.com/@scout2015",
  "author_name": "Scout & Suki",
  "width": "100%",
  "height": "100%",
  "html": "<blockquote class=\"tiktok-embed\"...",
  "thumbnail_url": "https://p16.muscdn.com/obj/tos-maliva-p-0068/06kv6rfcesljdjr45ukb0000d844090v0200010605",
  "thumbnail_width": 720,
  "thumbnail_height": 1280
}

2. Expression régulière pour extraire thumbnail_url

La regex suivante capture la valeur de thumbnail_url dans le JSON :

"thumbnail_url"\s*:\s*"([^"]+)"

Explication :

  • "thumbnail_url" — correspond à la clé JSON exacte.
  • \s*:\s* — accepte zéro ou plusieurs espaces autour des deux-points.
  • "([^"]+)" — capture tout ce qui se trouve entre les guillemets (l'URL), en excluant tout guillemet interne.

Démonstration sur un JSON exemple :

... "author_name": "Scout & Suki",  "thumbnail_url": "https://p16.muscdn.com/obj/tos-maliva-p-0068/06kv6rfcesljdjr45ukb0000d844090v0200010605",  "thumbnail_width": 720, ...

Le groupe de capture n°1 contient l'URL de l'image.

3. Utilisation en JavaScript

const json = `{ "thumbnail_url": "https://p16.muscdn.com/...", "thumbnail_width": 720 }`;
const match = json.match(/"thumbnail_url"\s*:\s*"([^"]+)"/);
const imageUrl = match ? match[1] : null;
console.log(imageUrl);
// → https://p16.muscdn.com/...

4. Utilisation en Python

import re
import requests

url_video = "https://www.tiktok.com/@scout2015/video/6718335390845095173"
resp = requests.get("https://www.tiktok.com/oembed", params={"url": url_video})
data = resp.json()

# Méthode directe (recommandée)
thumbnail = data.get("thumbnail_url")

# Ou via regex si vous traitez du texte brut
match = re.search(r'"thumbnail_url"\s*:\s*"([^"]+)"', resp.text)
if match:
    thumbnail = match.group(1)

print(thumbnail)
💡 Bonne pratique : si vous parsez du JSON, utilisez directement le parseur natif de votre langage (json.loads en Python, JSON.parse en JavaScript) et accédez à la propriété thumbnail_url. La regex reste utile lorsque vous devez extraire la valeur depuis une chaîne HTML ou un flux non structuré. Attention : la regex ne décode pas les échappements JSON (par ex. \/ ou &) que le parseur natif gère automatiquement.
